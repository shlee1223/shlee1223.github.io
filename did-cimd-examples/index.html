did:cimd examples

OAuth Client ID Metadata Documents published as resolution examples for the did:cimd method.

  • client.json: keys referenced through jwks_uri (jwks.json)
    did:cimd:shlee1223.github.io:did-cimd-examples:client.json
  • client-inline.json: keys carried inline in jwks
    did:cimd:shlee1223.github.io:did-cimd-examples:client-inline.json

No one holds the private keys. These clients cannot authenticate anywhere.
